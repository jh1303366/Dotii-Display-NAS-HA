# Dotii 固件效果图

本包包含 52 张 466×466 PNG，覆盖全部固件页面及主要状态。双击 index.html 可分类浏览，点击图片可查看原始尺寸。

图片直接使用当前 1.3.0-ha 固件的 state_ui.c、ha_ui.c、图标、字体和 LVGL 9.4 软件绘图生成，不是 AI 想象图。主机预览只替换 ESP32 的联网、存储和电源接口；未改动固件布局。

所有数值、任务、网络地址、电量、灯光和空调状态均为演示数据，没有为预览发送真实设备控制指令。Dotii 动态表情展示代表帧；关屏为全黑；自定义图片与 Bambu 相机内容依赖实际图片和视频源，本包同时提供文字页、无相机状态和明确标注的图片/相机占位示例。实际屏幕的颜色、亮度、旋转和触摸操作需刷入设备后验证。

预览中发现一处细节：新界面已修复空调详情页底部露出旧翻页按钮边缘的问题。
